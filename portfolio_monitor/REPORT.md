# 持仓日报：给 Claude 的写作要求

你在为一位使用 Trading 212 Stocks ISA 账户的英国个人投资者撰写每个交易日收盘后的简报。

## 步骤

1. 在仓库根目录运行 `python -m portfolio_monitor`，得到 JSON 数据：
   - `portfolio`：账户汇总和每个持仓。金额使用账户币种；`current_price` 和 `average_price` 使用该股票自己的币种（GBX 表示便士）。
   - `watchlist`：关注但尚未持有的股票代码。
2. 用网络搜索查询以下信息：
   - 当天涨跌幅较大，或仓位权重最大的几只持仓：最新的新闻、财报、评级变化，以及当日涨跌幅。
   - 关注列表里的每只股票：当前价格、当日涨跌，以及近期的重要消息、财报日期和估值概况。
3. 按下面的结构，直接在回复里写出完整报告。

## 报告结构

用中文和 Markdown，篇幅控制在一屏到两屏之间，先给结论再给细节。

1. **今日结论**：用 2 到 3 句话概括今天账户的表现，以及有没有需要行动的事。
2. **账户概览**：用表格列出总资产、现金、累计浮动盈亏和已实现盈亏。
3. **持仓表现**：用表格列出每只持仓的权重、浮动收益率和当日涨跌，并简要点评值得关注的几只。
4. **关注列表**：用表格列出每只股票的价格、当日涨跌和一句话要点；对看起来出现买入机会或需要警惕的股票，单独说明原因。
5. **风险提示**：
   - 仓位集中度：单只超过 20%、前五大合计占比。
   - 行业或地区是否过度集中。
   - 现金比例是否过高或过低。
6. **建议**：给出 1 到 3 条具体、可执行的观察或调仓思路，每条都写明理由。如果今天没有需要做的事，就写"维持现状"。

## 注意

- Stocks ISA 内的资本利得和股息在英国免税，不要建议与此相悖的税务操作。
- 数据或搜索结果缺失时如实说明，不要编造价格。
- 结尾用一句话提醒：本报告不构成投资建议。
- 不要提交或推送任何文件，也不要把持仓数据写进仓库。
